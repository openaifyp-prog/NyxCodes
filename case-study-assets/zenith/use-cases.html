Cinematic Reveals

To mimic the elegance of architectural forms, the hero text uses a staggered `@keyframes reveal` animation. Each line translates from y+100% to 0 with a cubic-bezier easing, creating a fluid text-reveal effect that feels organic, not mechanical.

Visual Silence

The project grid is defined by what isn't there. Large negative space, asymmetric layouts, and grayscale imagery that only saturates on hover (`grayscale-0`) allow the user to focus purely on the structural composition of the work.
