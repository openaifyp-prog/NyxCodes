Living Backgrounds

The app maps weather condition codes (e.g., '800' for Clear) to specific CSS classes. Each class triggers a unique animated gradient background (`.theme-rain`, `.theme-clear`), creating an immersive full-screen experience.

Asynchronous Fetch

Data fetching is handled via `async/await` to prevent UI blocking. The app bundles multiple API calls (Current + Forecast) into a single logical flow, parsing the JSON response into a normalized state object before updating the DOM.
