Glassmorphism Engine

The UI relies on a centralized set of CSS variables (`--glass-bg`, `--glass-border`) to control opacity and blur radius. This allows for real-time theme switching (Light/Dark) while maintaining the frosted glass aesthetic.

3D Flip Cards

Cards utilize `perspective: 1000px` and `rotateY` transforms to create a tactile 3D flip effect. The `backface-visibility: hidden` property ensures smooth hardware-accelerated transitions during the flip.
