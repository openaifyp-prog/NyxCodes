Quick Sort

An exceptionally efficient, cache-friendly partitioning algorithm that defines modern computational sorting.

Average CaseO(n log n)
Worst CaseO(n²)
SpaceO(log n)
StableNo

The Concept

Selection-based partitioning makes QuickSort one of the fastest general-purpose sorting algorithms. It thrives on the principle of "Divide and Conquer". By picking a Pivot, it reduces the problem into two sub-problems that are mathematically easier to solve. Once the pivot is placed, it stays in that position forever, progressively locking the array into order.

Working with Steps

  1. Pick a Pivot: Choose an element from the array (commonly the last element).
  2. The Partition: Rearrange elements so that all elements smaller than the pivot are on the left, and all larger elements are on the right.
  3. Finalizing Pivot: Swap the pivot into its correct sorted index.
  4. Recursion: Apply steps 1-3 to the left and right sub-arrays independently.
  5. Base Case: Stop when sub-arrays reach 0 or 1 elements.

Merge Sort

The gold standard for stable sorting, providing consistent performance across any dataset.

Time ComplexityO(n log n)
Space ComplexityO(n)
StableYes
MethodMerge

The Concept

Merge Sort is based on the philosophy that "Merging two sorted lists is easy." It recursively breaks an array into halves until each sub-array contains only one element. Then, it merges those elements back together in sorted order, building the solution from the bottom up.

Working Steps

  1. Base Case: If the array has 1 or 0 elements, it is already sorted.
  2. Divide: Find the midpoint and split the array into two halves.
  3. Conquer: Recursively call Merge Sort on both halves.
  4. Combine (Merge): Merge the two sorted halves into a single sorted array by comparing lead elements.

Bubble Sort

The quintessential teaching algorithm for introducing iteration and comparison.

Average CaseO(n²)
Best CaseO(n)
StableYes
TypeComparison

The Concept

Bubble Sort works by repeatedly swapping adjacent elements if they are in the wrong order. With each pass, the largest remaining element "bubbles up" to its correct position at the end of the array, much like air bubbles rising in water.

Steps

  1. Iteration: Loop through the array from left to right.
  2. Compare: Check if current element > next element.
  3. Swap: If true, swap them.
  4. Repeat: Continue until no swaps are needed in a full pass.

Insertion Sort

A robust, intuitive algorithm that handles small or nearly-sorted datasets with speed.

Small DataFast
AverageO(n²)
SpaceO(1)
OnlineYes

The Concept

Insertion Sort builds the final sorted array one item at a time. It's much like how you would sort a hand of playing cards: you take one card and "insert" it into its correct position relative to the cards you already hold.

Working Steps

  1. Initiate: Start at the second element (the 'key').
  2. Observe: Compare the key with elements to its left.
  3. Shift: Move elements larger than the key one position to the right.
  4. Insert: Place the key in its correct relative spot.
  5. Progress: Move to the next element and repeat until the array is fully processed.

A* Search

The industry standard for pathfinding, combining the precision of Dijkstra with the foresight of heuristics.

Time ComplexityO(E log V)
AccuracyOptimal
HeuristicAdmissible
MemoryHigh

The Concept

A* is an informed search algorithm. It essentially asks: "What is the shortest distance I've already traveled (**g**) plus the best guess of the remaining distance (**h**)?". This total cost (**f = g + h**) ensures the algorithm focuses its search towards the goal, ignoring paths that move in the wrong direction.

Working Logic

  1. Open Set: Maintain a priority queue of nodes to be explored, sorted by their 'f' score.
  2. The Heuristic: Calculate the Manhattan or Euclidean distance from the current node to the goal.
  3. Relaxation: For each neighbor, check if moving through the current node yields a lower 'g' score than previously known.
  4. Cycle: Extract the node with the lowest 'f' score and repeat until the goal is reached or the set is empty.

Mathematical Model

f(n) = g(n) + h(n)

Where g(n) is path cost, and h(n) is heuristic estimate.

Dijkstra's Algorithm

The Logic

Dijkstra is essentially A* without the heuristic (h=0). It explores equally in all directions, guaranteeing the shortest path in any graph with non-negative weights. It is the core logic behind modern network routing protocols like OSPF.

Breadth-First Search

A robust, layer-by-layer exploration method for unweighted grids.

The Concept

BFS treats a graph as a series of concentric waves. It visits all neighbors at distance 1, then all neighbors at distance 2, and so on. This makes it perfect for finding the "shortest path" in terms of number of steps (edges).

Working Steps

  1. Enlist: Add the starting node to a Queue.
  2. Examine: Dequeue a node and mark it as visited.
  3. Expand: Add all unvisited neighbors to the back of the Queue.
  4. Repeat: Continue until the Queue is empty or the target is found.

Recursive Backtracker

A randomized depth-first search that constructs intricate, perfect mazes.

The Concept

Commonly known as the "Depth-First Search" maze generator, this algorithm carves paths by moving to a random unvisited neighbor and pushing the current cell onto a stack. When it hits a dead end, it pops from the stack (backtracks) until it finds a cell with unvisited neighbors.

Working Steps

  1. Start: Pick a random starting cell and mark it visited.
  2. Explore: Look for unvisited neighbors.
  3. Tunnel: If found, move to a random neighbor, remove the wall, and push the cell onto a stack.
  4. Backtrack: If no neighbors exist, pop from the stack to find a previous cell with options.

BST Insertion

Dynamic data organization that balances search speed with insertion flexibility.

The Principle

Binary Search Trees (BST) maintain a strict order: Left < Root < Right. Insertion is the process of navigating this rule recursively until a null spot is found.

Step-by-Step

  1. Inquiry: Compare the new value with the current node.
  2. Branch: If smaller, recursively visit the Left. If larger, visit the Right.
  3. Action: If the chosen branch is empty, create the new node there.

In-Order Traversal

A graceful recursive walk that reveals the hidden sorted order of a BST.

The Magic

By visiting the Left Subtree, then the Root, then the Right Subtree, an In-Order traversal extracts all elements from a BST in perfect non-decreasing order.

Recursive Order

  1. Left: Recursively traverse the left subtree.
  2. Visit: Read/Print the data in the current node.
  3. Right: Recursively traverse the right subtree.
